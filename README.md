# 🌐 Cisco VLAN & Router on a Stick (ROAS) Lab

A comprehensive hands-on lab demonstrating **Inter-VLAN Routing** using the **Router on a Stick (ROAS)** methodology with Cisco CSR1000v and IOSvL2 switches on Eve-NG.

## 🎯 Project Objectives

- Create isolated broadcast domains using **VLANs** (VLAN 10: Accounting, VLAN 20: IT)
- Configure **802.1Q Trunk** links between switches and router
- Implement **Router on a Stick (ROAS)** for Inter-VLAN routing
- Deploy **Cisco IOS DHCP Server** for automatic IP assignment
- Verify end-to-end connectivity across VLANs and switches
